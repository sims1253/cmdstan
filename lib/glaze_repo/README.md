# Glaze Library

This directory should contain the Glaze C++ header-only library, required for BEVE format support.

## Installation

\`\`\`bash
git clone https://github.com/stephenberry/glaze.git glaze_repo
\`\`\`

Or download from: https://github.com/stephenberry/glaze

The \`include/glaze\` directory should be at \`glaze_repo/include/glaze/\`.
